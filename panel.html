🔍 Profile Lookup — Perplexity AI

When you drop a Name or Business item, EazyLyst will automatically search for social media and profile links using Perplexity AI.

You need a Perplexity API key to use this feature. Keys start with pplx-.

What gets searched?

👤 Names → LinkedIn, X / Twitter, Instagram, Facebook, GitHub, personal website
🏢 Business → Company website, LinkedIn, X / Twitter, Instagram, Facebook, YouTube
🔗 Links → skipped (already a URL)
