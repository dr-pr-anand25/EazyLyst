# Privacy Policy

Effective date: 2026-02-20

Short summary

- EazyLyst stores captured items and named lists locally on the user's machine. We do not transmit your captured text, URLs, lists, or timestamps to any server.

What we store locally

- Captured items: value, auto-assigned category, optional ID and timestamp.
- Named Lists and their contents.
- Local settings needed for the UI (overlay visibility, window position, etc.).

Automatic updates

- The app uses `electron-updater` to check GitHub Releases for new versions. Update checks request release metadata from GitHub; these requests do not include personally-identifying content from the app's stored items.

Telemetry and crash reporting

- EazyLyst does not include telemetry, analytics, or crash-reporting services by default. If you see a prompt or an opt-in request for crash reports in a future version, it will be clearly explained and optional.

Third-party components

- EazyLyst bundles standard open-source components (Electron / Chromium and related libraries). Those components are subject to their own licenses and third-party policies. We do not intentionally call external analytics or tracking endpoints.

Data exports and deletion

- You can export your collection or individual lists to CSV using the panel's Export feature.
- Use the panel's Discard/Delete actions to remove items and lists; data removed via the UI is deleted from local storage.

Contact and support

- For privacy questions or to request removal advice, open an issue: https://github.com/DanPolland8/EazyLyst/issues

Notes

- This document is intentionally short and aimed at end users. It may be updated; check the repo or the packaged app's release notes for changes.
